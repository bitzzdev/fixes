# Fixes

A practical collection of troubleshooting guides, device fixes, scripts, and system optimization notes. Documents are grouped by platform or technical area.

## Categories

- [Android](android/README.md): Android devices, ADB, apps, storage, battery, performance, and Termux.
- [Linux](linux/README.md): Linux distributions, desktop environments, boot, packages, scripts, and system maintenance.
- [Windows](windows/README.md): Windows troubleshooting and system fixes.
- [Network](network/README.md): Wi-Fi, hotspot, connectivity, and network troubleshooting.
- [Cross-platform](cross-platform/README.md): Workflows and fixes shared across platforms.

## Documentation principles

- Diagnose before changing settings.
- Prefer read-only checks before modifications.
- Avoid destructive commands unless the target and consequences are explicit.
- Record exact device/build context and measured results.
- Include verification and rollback instructions where applicable.
